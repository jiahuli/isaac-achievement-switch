三、怎么用

  1. 进游戏后按 ~ 打开调试控制台，顶部菜单栏会出现「成就开关」。
  2. 把「允许本局解锁成就」关掉。
  3. 开一局新的 —— 开局瞬间 mod 会把本局标记为「不解锁成就」。
  4. 想恢复成就：把开关打开，然后再开一局新的。
菜单里的元素作用
☑ 允许本局解锁成就主开关，关掉 = 本局不解锁成就
按钮「关闭成就（不重开…）」试试不重开就关掉（本版引擎不行，会给明确提示）
按钮「立即重开本局生效」以同角色 / 同难度 / 同种子重开本局，必定生效

确认生效的方法：屏幕会弹 ACHIEVEMENTS / DISABLED 提示条， 并且 HUD 上出现划掉的奖杯图标 —— 那是游戏原生的「本局不解锁成就」标志。

四、它到底做了什么（为什么只能这么做）

原版忏悔+ 的成就门控是引擎内部的 Seeds::AchievementUnlocksDisallowed()，Lua 侧只有只读的 Seeds:IsCustomRun()，没有一个 setter。真正可用的原生开关只有一个： 「本局是不是自定义局 / 种子局」（也就是大家说的「种子局拿不到成就」）。

所以本 mod 的做法是：把本局重新标记为一个自定义局 —— 用同一个角色、同一个挑战、同一个难度、同一个种子重开一次，地牢布局和你本来要打的那局一模一样。

  • 自动重开只在 全新开局的瞬间 + 单人 + 非读档续关 时发生，一局最多两次，失败就本次游戏内停用并提示。
  • 局内手动关开关绝不自动重开（免得毁掉打到一半的进度），只会提示「下一局生效」，想立刻生效自己点重开按钮。
  • 重开后会核对难度 / 挑战有没有被改动，变了会明确告诉你。

已知限制

  1. 本局一旦成为自定义局就撤不回来 —— 重新打开成就必须开新的一局。
  2. 中途关多半不生效，只能重开本局或等下一局。
  3. 多人 / 协作局不自动重开（重开只能指定一个角色，会破坏队友）。
  4. 存盘续关的局引擎不保持该标记，续关后本局可能正常解锁成就（mod 会提示，但不会替你重开）。
  5. 每日挑战是特殊判定，本 mod 不去动它。

五、排错

日志在 Documents\My Games\Binding of Isaac Repentance+\log.txt，搜 [AchievementSwitch]：

[INFO] - Lua Debug: [AchievementSwitch] 新局开始：允许成就=false 引擎已禁止=false(repentogon) 难度=2-贪婪(property) ... 续关=false 人数=1
[INFO] - Lua Debug: [AchievementSwitch] 已排队：开局自动重开（第 1 次，等 2 帧后执行）
[INFO] - Lua Debug: [AchievementSwitch] 通道 B：已要求重开为自定义局（角色=3 挑战=0(property) 难度=2-贪婪(property) 种子=123456789）
[INFO] - Lua Debug: [AchievementSwitch] 通道 B 成功：重开后本局已被引擎标记为不解锁成就
  • 看到 通道 B 成功 = 成了；难度= 那列可以核对贪婪 / 困难有没有被改。
  • 搜不到任何 [AchievementSwitch] = mod 没加载：确认路径是 mods\achievement_switch\main.lua，并在日志里搜 There was an error running the lua file。
